# Vardhan portfolio

A portfolio for Srivardhan Reddy Kolan, focused on DevOps, cloud platforms, and production reliability. Built with Next.js, React, TypeScript, and Tailwind. The site exports static HTML, CSS, and JavaScript; no server, database, or paid APIs are required.

## Run locally

Use Node.js 22 (`.nvmrc`) or another compatible supported version. The redesign was also built locally with Node.js 24.

```bash
npm install
npm run dev
```

Open http://localhost:3000. The santifer reference project runs separately on port 5173.

## Editing

- `content/portfolio.ts`: profile, roles, technical skills, work examples, and credential links.
- `components/portfolio.tsx`: page sections and interactions.
- `app/globals.css`: layout, typography, colors, mobile breakpoints, and reduced-motion support.
- `app/layout.tsx`: page metadata and theme provider.
- `public/SrivardhanReddy-Resume.pdf`: current public résumé. `public/resume.pdf` is kept in sync for existing links.

The current content combines the Bluebeam and MKS Vision source PDFs. The owner corrected the work history using the supplied experience screenshot: Nemetschek/Bluebeam 2025-present, MKS Vision 2024-2025, AVYA 2018-2024, CDK Global 2017-2018, and Tech Mahindra 2013-2015. Only years are displayed because the screenshot does not specify months.

The public resume is generated by `scripts/build_resume.py` (Python + ReportLab). The two-page output is `output/pdf/Srivardhan_Reddy_Kolan_Resume.pdf`; the generator also updates both public download paths. Original source PDFs are preserved.

`components/command-demo.tsx` animates illustrative commands and output while in view. The navigation pause control stops animations; reduced-motion preferences display completed command output immediately.

The infrastructure illustrations are conceptual, not diagrams of an employer's internal systems. Work examples summarize the résumé and do not claim unverified savings or performance metrics.

## Checks

```bash
npx tsc --noEmit
ESLINT_USE_FLAT_CONFIG=false npx eslint components/portfolio.tsx content/portfolio.ts app/page.tsx app/layout.tsx
npm run build
```

`npm run build` exports the site into `out/`. Stop the dev server before building: both commands otherwise use `.next` concurrently.

## Cloudflare Pages

The existing project is `vardhan`, connected to `ksrivardhanreddy/vardhan`. Production deploys from `main`; other branches can create preview deployments.

For a direct static deployment, use:

| Setting | Value |
| --- | --- |
| Build command | `npm run build` |
| Output directory | `out` |
| Root directory | repository root |
| Node version | 22 |

Cloudflare Pages is configured for the static settings above. The previous deployment used `npx @cloudflare/next-on-pages@1` with `.vercel/output/static`. See `docs/DEPLOYMENT.md` for the original website archive and rollback details.

No Cloudflare plan upgrade is needed for the current static site. Future server-side or AI features need their own runtime, usage, and cost assessment.
